# Core technology

- [Nuxt](https://nuxt.com/)
- [Nuxt UI](https://ui.nuxt.com/)

# Setup

Make sure to install dependencies:

```bash
pnpm install
```

## Development Server

Start the development server on `http://localhost:3000`:

```bash
pnpm dev
```

## Production

Build the application for production (SPA mode):

```bash
pnpm generate
```
